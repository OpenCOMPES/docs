Diagnostics#

This module contains diagnostic output functions for the sed module

sed.diagnostics.plot_single_hist(histvals, edges, legend=None, **kwds)[source]#

Bokeh-based plotting of a single histogram with legend and tooltips.

Parameters:

  • histvals (numpy.ndarray) – Histogram counts (e.g. vertical axis).

  • edges (numpy.ndarray) – Histogram edge values (e.g. horizontal axis).

  • legend (str, default: None) – Text for the plot legend. Defaults to None.

  • **kwds –

    • tooltip: Tooltip formatting tuple. Defaults to [(“(x, y)”, “($x, $y)”)]

    Additional keyword arguments are passed to bokeh.plotting.figure().quad().

Returns:

An instance of ‘bokeh.plotting.figure’ as a plot handle.

Returns:

bokeh.plotting._figure.figure –

sed.diagnostics.grid_histogram(dct, ncol, rvs, rvbins, rvranges, backend='matplotlib', legend=True, histkwds=None, legkwds=None, **kwds)[source]#

Grid plot of multiple 1D histograms.

Parameters:

  • dct (dict) – Dictionary containing the name and values of the random variables.

  • ncol (int) – Number of columns in the plot grid.

  • rvs (collections.abc.Sequence) – List of names for the random variables (rvs).

  • rvbins (collections.abc.Sequence) – Bin values for all random variables.

  • rvranges (collections.abc.Sequence[tuple[float, float]]) – Value ranges of all random variables.

  • backend (str, default: 'matplotlib') – Backend for making the plot (“matplotlib” or “bokeh”). Defaults to “matplotlib”.

  • legend (bool, default: True) – Option to include a legend in each histogram plot. Defaults to True.

  • histkwds (dict, default: None) – Keyword arguments for histogram plots. Defaults to None.

  • legkwds (dict, default: None) – Keyword arguments for legends. Defaults to None.

  • **kwds –

    • figsize: Figure size. Defaults to (6, 4)
